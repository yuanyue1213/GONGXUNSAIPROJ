# STM32H743ZIT6 引脚分配

> 依据 `SCH_Schematic1_2026-09-08(1).pdf` 整理。下表中的 TX/RX 均以 STM32H743 为视角。

## 串口

| 接口 | 用途 | TX 引脚 | RX 引脚 | 原理图接口 |
| --- | --- | --- | --- | --- |
| UART4 | 摄像头 | PA0 | PA1 | H7 |
| UART5 | 雷达 | PB13 | PB12 | H8 |
| UART7 | 九轴传感器 | PF7 | PF6 | H10 |
| USART1 | 四路电机 | PB14 | PB15 | H1、H2、H3、H4 |
| USART2 | 单独电机 | PA2 | PA3 | H5、H6 |
| USART3 | 独立串口 | PB10 | PB11 | H18 |
| USART6 | 独立串口 | PG14 | PC7 | H23 |

## PMW3901 光流（SPI1）

| 功能 | 引脚 | 原理图网络名 |
| --- | --- | --- |
| SCK | PA5 | PA5_SPI1_SCLK |
| MOSI | PA7 | PA7_SPI1_MOSI |
| MISO | PA6 | PA6_SPI1_MISO |
| CS | PA4 | PA4_CS |
| MOT | PB0 | PB0_MOT |
| RST | PB1 | PB1_RST |

PMW3901 接口为 U3，另外连接 `3.3V` 和 `GND`。

## TFTLCD

| 功能 | 引脚 | 原理图网络名 |
| --- | --- | --- |
| MOSI | PB2 | PB2_LCD_MOSI |
| SCK | PC10 | PC10_LCD_SCK |
| MISO | PC11 | PC11_LCD_MISO |
| CS | PE2 | PE2_LCD_CS |
| RS | PD11 | PD11_LCD_RS |
| CTR / 背光控制 | PE1 | PE1_LCD_CTR |
| RST | PE0 | PE0_LCD_RST |
| PEN | PE3 | PE3_LCD_PEN |
| WR | PD5 | PD5_LCD_WR |
| RD | PD4 | PD4_LCD_RD |
| 备用 CS | PD7 | PD7_LCD_CS |

当前 TFTLCD 外接接口 H22 使用 8 根线：`3.3V`、`GND`、`PB2`、`PC10`、`PE2`、`PC11`、`PD11`、`PE1`。

## PWM 输出

| 通道 | 引脚 | 原理图网络名 | 原理图接口 |
| --- | --- | --- | --- |
| PWM1 | PA8 | PA8_PWM1 | H25 |
| PWM2 | PC8 | PC8_PWM1 | H25 |
| PWM3 | PC6 | PC6_PWM1 | H25 |

每个 PWM 接口同时提供 `8.4V` 和 `GND`。

## 其余引出引脚

下列引脚也已从核心板排针引出，但在本版原理图中没有指定外设用途：

`PF1`、`PF2`、`PF3`、`PF4`、`PD0`、`PD1`、`PD2`、`PD3`、`PD6`、`PD8`、`PD9`、`PD10`、`PD12`、`PD13`、`PD14`、`PD15`。

## 接线注意事项

- 串口应交叉连接：STM32 TX 接外设 RX，STM32 RX 接外设 TX。
- 所有外设必须与 STM32 共地。
- `3.3V`、`5V`、`8.4V` 和 `12V` 电源不可混接。
- 原理图网络名中的 `UART_TX`、`UART_RX` 表示 STM32 端信号方向。
