# 显式视觉校准与撤销

校准速度、目标点、比例、搜索范围及识别窗口等参数统一在 `App/Inc/robot_config.h`，旧 `mission_config.h` 只保留包含入口。

搜索以本次校准起点为固定参考，目标循环为 `(前后,左右)=(+100,0)→(-100,0)→(0,+50)→(0,-50) mm`。因此第一轮实际移动为：前100、后200、前100再左50、右100。只有到达完整目标点才重新识别；换轴途中不识别。第二轮从右侧点移动到前方点：前100再左50，此后继续相同目标循环。不是按相对步长前100后100往复。

在 `App/Inc/mission_flow.h` 编写校准步骤，站点宏不再自动校准：

```c
FLOW_ALIGN(TASK_TABLE,FLOW_BATCH_1), // 原料台，使用第一批颜色
FLOW_PICK_RAW(FLOW_BATCH_1),        // 或 FLOW_ARM(my_action)
FLOW_STOW(),                       // 返回前收臂，避免带着伸出的机械臂移动
FLOW_UNALIGN(),                    // 抵消校准位移，回到校准前的车体位置
```

视觉模式：`TASK_TABLE` 原料台，`TASK_RING` 中间圆环，`TASK_OCCUPIED` 有物料的工位。TABLE/OCCUPIED 使用所选二维码批次的颜色，前面必须安排扫码；RING 固定识别中间圆环 2，不使用批次数据。

校准仍执行粗调搜索和一次精调。搜索按固定起点的前100、后100、左50、右50 mm四个目标循环，前点到后点实际后移200 mm，每个完整目标点后重新识别。所有校准移动的指令距离都累计为车体前后、左右净位移，包括搜索、粗调和精调。

`FLOW_UNALIGN()` 先抵消左右位移，再抵消前后位移，不会重走完整搜索路径。零净位移的轴不移动。返回后清除记录，下次校准重新记录；没有校准记录就撤销、嵌套校准、未撤销就结束或插入路线平移/转向，都由流程检查拒绝，避免坐标参考改变。机械臂动作、取放和收臂可放在校准与撤销之间。

默认比赛流程已为八个站点分别显式插入校准、收臂和撤销。也可以只写站点取放而不校准，由编写者确认车体已经在正确位置。

粗调搜索及撤销速度设为1500 RPM，精调设为1000 RPM，参数集中在 `stm32/yundongv2/App/Inc/robot_config.h` 的 `MISSION_ALIGN_COARSE_RPM`、`MISSION_ALIGN_FINE_RPM`、`MISSION_UNALIGN_RPM`。实际短距离运动还受原有加速度影响，并不保证达到设定速度；识别稳定窗口和运动结束余量保留。

记录是指令位移，没有编码器或外部定位验证。打滑、丢步和标定误差会影响返回精度，不能把撤销完成视为实测回到原点。运动失败时退出本轮并停车，不自动尝试恢复到原点。

最终精调移动结束后，TABLE/OCCUPIED会在当前位置重新采样一次，只更新圆台轨迹或工位锚点，不继续修正车体。这样NEAR/PICK不会使用移动前的缓存。RING不保存后续抓取缓存，无需额外刷新。站点每次PICK前都将底座恢复到ARM_ALIGN_BASE（默认180°），避免前一次取放改变观察方向。
