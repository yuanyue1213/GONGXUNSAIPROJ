# 显式视觉校准与撤销

校准速度、目标像素、比例、搜索范围和原料粗调距离统一在 `stm32/yundongv2/App/Inc/robot_config.h`。动作顺序在 `App/Inc/mission_flow.h`，站点宏不会自动校准：

```c
FLOW_ALIGN(TASK_TABLE,FLOW_BATCH_1), // 原料单块定位；批次仍用于二维码和抓取顺序
FLOW_PICK_RAW(FLOW_BATCH_1),
FLOW_STOW(),
FLOW_UNALIGN(),                    // 抵消本次搜索及校准的净位移
```

`TASK_TABLE`从已HSV标定六色中选择离目标像素最近的物块，3帧位置稳定后将中心取整到整像素再回复，避免0.1像素拟合抖动触发固定粗步。三位target只作批次标签，不限制物块颜色，不求圆台或椭圆。

底座转180°，原料粗调按误差方向固定移动前后100 mm、左右5 mm，先前后后左右，零差轴不动。图像X正向对应B、Y正向对应L，负向反转。然后重新TABLE，按1.090819 mm/像素精调：两轴偏差都≤1像素时提前结束，已达标轴不再移动。最多修正3次，每次移动后都重新识别；第三次后仍超差也按当前位置继续取放，全部修正位移照常累计，任务完成后正常撤销。

NEAR只检查固定目标像素（默认256,160）周围半径12像素方框。目标色匹配至少50%、连续3帧才回复位置2；框外同色不算成功，不依赖TABLE缓存。未满足时回复NONE，STM32等待。

`TASK_RING`仍识别中间圆环2；`TASK_OCCUPIED`仍识别所选批次三色。两者按像素距离粗调一次，再按上述1像素阈值循环精调。OCCUPIED最后的识别同时刷新左中右锚点，供后续PICK使用，不额外重复请求。TABLE/OCCUPIED前须先扫码，站点每次PICK前底座恢复180°。

没识别到目标时的搜索与上述固定粗调不同：相对本次校准起点，目标依次为 `(前后,左右)=(+100,0)→(-100,0)→(0,+50)→(0,-50) mm`。前点到后点实际后退200 mm；换轴时先回到起点轴坐标，再移向新目标。每到一个完整目标点重新识别，粗调请求发出满1500 ms后收到明确NONE才继续搜索，无回复保持等待。

粗调、搜索、撤销设为1500 RPM，精调1000 RPM，实际受加减速限制。结果按请求编号、类型、目标接收并回复ACK，相机停止该任务等待新请求。

所有成功下发并等待结束的搜索、粗调和精调位移都累计为车体净位移。`FLOW_UNALIGN()`先抵消左右，再抵消前后，零净位移轴不动，不重走完整搜索路径。未撤销就插入路线平移/转向、嵌套校准或结束，以及无记录时撤销，均由流程检查拒绝。机械臂动作、取放和收臂可放在校准与撤销之间。

记录是指令位移，没有编码器或外部定位验证；打滑、丢步会影响返回精度。运动失败时退出本轮并停车，不自动恢复原点。默认有六组校准与撤销：两批加工均在圆环校准后先放三件，再按同批二维码工位原地直接取回三件，不发送OCCUPIED/PICK请求；取回完成后统一收臂、撤销。空暂存区使用圆环定位；码垛使用下层三色物块OCCUPIED校准，最终识别刷新左中右锚点，再逐件用PICK查询目标颜色所在工位。用户微调的路线距离保持原值。

堆叠的OCCUPIED只按实际X坐标排列左/中/右工位，不要求三物块排成一行或水平间距均匀。颜色唯一性、物块间距、面积比例及稳定帧判断仍保留；圆环RING的排列检查不变。
