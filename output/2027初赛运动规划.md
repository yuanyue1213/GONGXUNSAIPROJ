## 1. 规则决定的执行顺序

任务码四组：第一批颜色顺序 + 第一批粗加工及暂存位置 + 第二批颜色顺序 + 第二批粗加工位置。颜色编号：1红、2黄、3蓝、4绿、5黑、6浅蓝。

以 `156+123+516+231` 为例：

|阶段|按顺序操作的物料|对应位置|
|---|---|---|
|第一批原料取料|红、黑、浅蓝|逐个放入车载槽位A、B、C|
|第一批粗加工放置|红、黑、浅蓝|1、2、3号圆环|
|第一批粗加工取回|红、黑、浅蓝|从1、2、3号圆环取回车上|
|第一批暂存放置|红、黑、浅蓝|1、2、3号圆环|
|第二批原料取料|黑、红、浅蓝|逐个放入车载槽位A、B、C|
|第二批粗加工放置|黑、红、浅蓝|2、3、1号圆环|
|第二批粗加工取回|黑、红、浅蓝|从2、3、1号圆环取回车上|
|第二批暂存码垛|黑、红、浅蓝|第一批黑、红、浅蓝上方，即2、1、3号位|

第二批暂存位置由第一批的颜色—位置关系查询得到，不能直接使用第四组。第一批三个物料全部放完粗加工区，才能进入取回阶段。每次取一个，存到车上后才取下一个。设计按每次运输三件，以减少往返；规则允许运输1—3件。跨工位前夹爪必须空，物料已存入车上。

## 2. 路线节点和底盘运动

采用世界坐标：示意图左下角(0,0)，向右X增加、向上Y增加，单位mm。地图为2400×2400。以下节点是示意图上的初始设计值，不是规则指定停车点。

|节点|建议初始坐标|用途|
|---|---|---|
|S1|(2250,2250)|固定起点，右上启停区中心|
|S2|(2250,150)|固定终点，右下启停区中心|
|Q|(2200,1200)|右侧二维码搜索、接近区|
|C|(1200,1200)|十字中心通行节点|
|R|(1200,2200)|上侧原料区观察、接近节点|
|P|(1200,300)|下侧粗加工观察、接近节点|
|T|(300,1200)|左侧暂存观察、接近节点|
|NE|(2200,2200)|外围右上节点|
|SE|(2200,300)|外围右下节点|
|NW|(300,2200)|外围左上节点|
|SW|(300,300)|外围左下节点|

Q和R要按现场随机摆放的位置重新建立；停靠距离按机械臂可达范围、相机视野、车体轮廓和平台碰撞距离标定。从S1先经过NE=(2200,2200)，再沿右侧灰色车道前往Q；结束段从SE沿右侧灰色车道进入S2。

首选路线：

```text
S1 → NE=(2200,2200) → Q（读完整任务码）→ NE → R
R → C → P                  第一批到粗加工
P → C → T                  第一批到暂存
T → NW → R                 返回原料
R → C → P                  第二批到粗加工
P → C → T                  第二批码垛
T → C → Q → SE → S2         完成后进入终点
```

这些边为候选通道。外围可增加R—NE—Q—SE—P、P—SW—T等绕行路径，形成带障碍占用状态的图；ESP32用最短路径算法选择当前可通行路径。原料和二维码位置改变时，新增连接到附近灰色车道的接近节点，不能横穿淡黄色区。

结束段中的Q表示右侧通道连接点，不再次扫码；二维码接近点随现场改变时，应保留独立的右侧通道节点用于通行。结束段候选绕行：T→SW→P→SE→S2，实际选择以障碍占用情况为准。S2为终止状态，不再返回S1；到达后停车、收拢机械臂并显示完成统计。

当前底盘支持F/B/L/R定距平移：优先保持底盘航向不变，用前后运动、横移组合沿轴线到节点。世界坐标位移需根据实际底盘航向转换为车体方向，不能把世界X直接写死为某个串口字母。工位朝向优先通过机械臂基座调整；机械臂与相机无法覆盖该方向时，再在经过车体扫掠验证的宽阔区域转动车体，之后重新定位。

车头朝下且没有转动车体时，按协议中F前进、B后退、L左平移、R右平移的定义，映射如下；上车测试确认实际接线与协议方向一致后使用：

|世界方向|车体指令|
|---|---|
|向下，-Y|F，前进|
|向上，+Y|B，后退|
|向右，+X|L，左平移|
|向左，-X|R，右平移|

例如：S1先到NE=(2200,2200)，再向下到扫码区域用F；R沿中轴向下到P用F；P向上到C用B；C向左到T用R；T向上到NW用B，再向右到R用L。结束时T向右经过C到右侧通道用L，再向下进入S2用F。每段均先检查通道并等待到位。若实际航向改变，必须更新坐标变换，不能继续沿用本表。

按初始设计坐标S1=(2250,2250)、NE=(2200,2200)、Q=(2200,1200)，且车头朝下，起步段分解为：先F前进50mm到(2250,2200)，再R右平移50mm到NE，停稳后F前进1000mm到Q。进入Q后的实际扫码接近量根据现场二维码位置和视觉结果调整。

每段运动：确认机械臂收回及车载物料状态 → 检查通道 → 下发定距 → 等待到位 → 停稳 → 修正位置/航向 → 下一段。长距离可分段监测，但不能把电机脉冲到位视为世界坐标一定到位。

## 3. 灰色车道和随机障碍

规则中间十字车道宽400mm，机器人初始投影不超过300×300mm。若实际宽300mm，理想居中时每侧只有50mm余量；误差预算还要包含轮胎滑移、定位误差、突出部件及携带物料。展开机械臂的实际扫掠范围需单独检查，运输时使用收拢姿态。

对灰色可通行地图按车体半宽及定位余量向内收缩，对障碍按车体半宽、障碍半径和余量向外膨胀。原规则随机障碍直径50mm、高100mm：窄车道中间遇到障碍，很可能没有侧绕空间，应将该图边标记不可通行，选择外围路径，不能靠盲目横移越过车道边界。

移动时需要能覆盖行进方向的障碍感知与车道/定位反馈。现有圆心识别只能做工位定位，不能代替道路避障。没有可行路径时停住等待，不能继续执行原定距离。

## 4. 原料区取料动作

1. 在R附近找到转盘，调整观察位置；确认三种任务颜色，不用画面从左到右顺序代替任务顺序。
2. 判断目标在连续图像中是否停稳。规则转盘方向随机，停留次数及时间以现场为准，不写死停4秒或固定转向。
3. 选本轮下一个颜色，获取实际抓取高度对应的抓取点。当前底部圆心可作为物料落地点定位，但斜视时它与夹爪抓取高度的投影不同，要标定相机—夹爪关系与高度视差。
4. 低速接近，底盘停稳；夹爪张开 → 到物料上方 → 下降到抓取高度 → 夹紧 → 垂直抬到安全高度 → 收回 → 对准车载槽位 → 放入 → 确认存入成功。
5. 更新颜色—车载槽位记录，继续取下一种颜色。目标重新转动、位置跳变或置信度不足时撤销下降，抬起并重新识别。

取料时不要求为了每个物料都转动车体。优先机械臂伸缩/基座定位；超出机械臂工作空间时，在安全停靠范围内小幅调整底盘。

## 5. 粗加工区放置、取回

在P附近先识别三环，校正工位方向和距离，再建立数字编号—图像中心对应关系。规则图3存在3、2、1排列，当前 `RINGS` 仅为图像从左到右三个中心，必须识别数字或使用经过核验的工位朝向映射，不能默认左环为1号。

从车载槽位按当前批次颜色顺序取出物料，到对应编号圆环正上方，垂直下降、张开、抬升、收回。根据机械臂可达空间决定整组三环一次停车完成，还是沿平台方向移动到各环前方；每次移动之后重新测量，不能把旧坐标直接用于新的相机位姿。

全部三件放完后，按该批相同颜色顺序从各圆环取回车上，再去暂存区。取回时用物料颜色/位置确认目标；被遮挡圆环可用其余可见边缘或工位已校验坐标辅助，不强求每帧都看到三组完整圆环。

最高分内环外径为物料最大直径+3mm，理想径向余量仅1.5mm，因此要联合校正底盘位置、工位方向及相机—夹爪偏差。建议把最终落点误差目标设为约1mm并实测验证；亚像素圆心不等于机械系统达到该精度。现有一次对准不复测，需要在ESP32规划中增加停稳后的再次测量和有限次数修正。

## 6. 暂存和码垛

第一批：在T定位，按第二组位置逐个放置，保存颜色、实际所在编号和放置验证结果。

第二批：按第三组颜色顺序查询第一批对应物料。基座朝向、机械臂伸缩位置按实际底层物料中心重新定位，而不只用印刷圆环的中心。第二层放置Z高度以实测第一层高度和夹持姿态标定；规则图5物料总高60mm，可作为初值，不能直接当作所有动作Z坐标。

抓住上层物料 → 抬到能越过已放物料的高度 → 移到同色底层上方 → 低速垂直下降 → 到支撑高度释放 → 垂直抬升 → 收回。先抬再横移，避免夹爪和物料扫碰已有码垛。验证后更新完成统计。

## 7. 速度、反馈与实现顺序

先沿用已验证的底盘速度45 RPM做无物料路线测试；进入工位降速、最终对准用已标定的细调速度。带料、转弯、码垛的速度通过稳定性实测确定，不直接使用电机最大速度。现有抓取STATE_V2合成速度与底盘MOVE速度含义不同，不能统一套用一个上限。

现有ESP32代码为校验转发桥，STM32本地判断到位，应用层没有完成/失败回包。自主规划需补充带序号的接受、忙碌、完成、失败、状态查询及停止接口；收到完成并完成视觉/状态核验后，才能推进任务。通信超时先查询实际状态，不能自动重发抓取动作。舵机按时长结束不等于抓取成功，应补充视觉或传感器核验。

视觉输出需增加任务码、每个物料的颜色与圆心、环编号映射、检测时间/有效性，并支持原料区少于三件及圆环被物料遮挡的情况。现有 `material_circle.py` 只选完整三件，第一次取走后通常无法继续输出，因此不能原样用于整轮原料取料。现有 `RINGS` 接口可保留供STM32对准，但ESP32需要额外的目标语义信息。

分阶段落地：

1. 空载验证S—Q—R—P—T路线，校准移动方向、距离、航向及安全边界。
2. 单工位、单物料完成取料—车载槽位—放料，并确认反馈。
3. 三件第一批全流程，验证颜色、槽位、编号映射。
4. 第二批不同放置顺序和同色码垛。
5. 最后加入随机原料/二维码位置、障碍绕行和失效恢复。

每次测试保留当前位置、任务状态、动作序号、车载库存和暂存库存日志。赛中显示完整任务码、正确抓取/放置次数及完成情况；当前规划固定从S1启动，在S2结束。
