# JY901S当前配置：9600、10Hz

2026-10-18 接线更新：JY901S 使用 USART3（PB11 RX、PB10 TX）；ESP32 使用 UART5（PB12 RX、PB13 TX），115200。PF6/PF7 已不再配置为陀螺仪串口。


用户指定固定9600、10Hz。此设置替代前版115200自动波特率搜索；只影响STM32 USART3与JY901S，ESP32、摄像头、电机串口保持各自原设置。

- STM32 USART3：PB11 RX、PB10 TX、AF7、9600、8N1。
- 模块TX→PB11，模块RX←PB10，共地。
- 启动等待1500ms，在9600下读取参数；没有回应时仅在9600再重试一次，不扫描其他速率，也不发送BAUD修改指令。
- 输出内容RSW=12（0x0C，角度+角速度），RRATE=6（0x06，10Hz），读回BAUD期望2（9600）。若模块已是其他速率，需要在模块端恢复9600，本程序不会把它从其他波特率迁移过来。
- 配置每项前单独解锁，写`FF AA 02 0C 00`、`FF AA 03 06 00`，读回验证后解锁保存。参数已正确则跳过修改与保存。
- 10Hz每100ms一组数据，两类帧共22字节，8N1占用约2200bit/s；不能将50Hz双帧的11000bit/s塞入9600。
- 初始化仍验证寄存器及两类新鲜数据，不会因为设置9600就自动允许闭环运动。角度与角速度各至少10帧，新鲜度上限仍200ms。控制实际更新随10Hz角度帧到达，20ms只是调度下限。

本次程序和App界面同步更新；ESP32可继续使用当前版本。生成STM32 HEX及App APK，未自动烧录。

调试期间曾在旧固件运行中通过ST-Link临时将UART7分频改为`0x30D4`（120MHz内核时钟对应9600），同步更新UART句柄与诊断中的波特率字段；未修改Flash，也未重启配置状态机。只在RAM/寄存器中生效，复位恢复旧固件设置。当时在9600下监听仍为0接收字节，不能据此宣称陀螺仪已经通信正常。

验证：固定9600且禁止BAUD写入的初始化模拟、默认10Hz、参数已正确时不保存、错误波特率不迁移、延迟启动、有界重试、读回和数据失败保护，以及100ms角度更新下前进/后退的距离与航向模拟。
